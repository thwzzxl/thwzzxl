
# Arthur Henrique

I like building things, whether it's a Discord bot, a Roblox game, or a website.

Most of my projects started with a random idea that I decided to turn into something real. I usually figure things out as I go, breaking stuff, fixing it, and learning along the way.

Right now, I'm mostly working with Python, but I also mess around with web development and Roblox Studio.

### What I've built

**Steal a Sword** — Roblox game

One of my biggest projects so far. A multiplayer game where players collect swords, earn money, upgrade their bases, and steal from each other.

Worked on the game's economy, inventory, data saving, base protection, equipment, and other systems.

**Heavenly** — Discord community

A Discord server I worked on, including custom Python bots for verification, role management, and automation.

**Confeitaria Saturno** — Website

A responsive website for a bakery, with a product catalog, WhatsApp integration, and a design made for both desktop and mobile.

**Other stuff**

I've also made smaller Python programs, interactive websites, and experimented with different game ideas in Roblox Studio.
